Privacy

Last updated September 27, 2026.

Who this covers

The Counter posts picks for games on YouTube, on X and on this site. Its uploader is a small program that runs on the channel owner's own computer and uploads the channel's own videos, thumbnails and playlist entries to the channel's YouTube account.

YouTube API Services

The uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the uploader accesses and stores

  • It uploads the channel's own videos and thumbnails, sets their titles, descriptions and settings, and adds them to the channel's own playlists.
  • It reads the channel's name and ID to confirm which channel it is uploading to.
  • It stores one sign-in token on the channel owner's computer, readable only by that account. It stores no other data from YouTube.
  • It does not access, collect, store or share data about viewers or any other YouTube user, and it sells nothing.

This website

This site sets no cookies and runs no analytics or tracking. It is hosted on GitHub Pages; GitHub's handling of visitor data is described in the GitHub Privacy Statement.

Revoking access and deletion

The channel owner can revoke the uploader's access at any time on the Google Account permissions page. Any data the uploader stores from YouTube API Services is deleted within 7 days of a request or of access being revoked, and stored API data is refreshed or deleted within 30 days.

Contact

Questions about this policy can be sent by opening an issue at github.com/CounterDecides/counterdecides.github.io/issues.
